| `qa-worker-scan` | Node + ts-morph | 2 vCPU / 4GB | Queue Driven (`scan-jobs`) |
| `qa-worker-ai` | Node + LLM SDK | 1 vCPU / 2GB | Queue Driven (`ai-jobs`) |
