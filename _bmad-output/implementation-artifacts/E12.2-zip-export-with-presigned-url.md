## Acceptance Criteria Summary

- **AC1: Given approved job When POST export type=zip Then presigned URL returned, valid 15 minutes**:
  - Implemented `generatePresignedDownloadUrl(key, 900)` in `@qa-automater/shared` (`packages/shared/src/storage/index.ts`).
  - Enhanced `exportGenerationJob` in `GenerationJobsService` (`apps/api/src/stories/generation-jobs.service.ts`) to return `download_url` with 15-minute expiration metadata (`expires_in_seconds: 900`, `expires_at`).
  - Configurable expiration fallback supported via `process.env.EXPORT_PRESIGNED_EXPIRATION_SECONDS`.

- **AC2: Given ZIP contents When extracted Then includes spec, PO, README.qa-automater.md, .env.example**:
  - Implemented `createTestZipArchive()` in `@qa-automater/shared` (`packages/shared/src/storage/zip-archiver.ts`) using `JSZip`.
  - ZIP file includes:
    - Spec files (`tests/specs/*.spec.ts`)
    - Page Objects (`tests/page-objects/*.page.ts`)
    - `README.qa-automater.md` (Setup & Execution walkthrough)
    - `.env.example` (Redacted environment placeholders)
  - Embedded credentials/secrets in test artifacts are automatically redacted before packaging via `sanitizeArtifactCredentials()`.
