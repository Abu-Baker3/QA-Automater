## Acceptance Criteria Summary

- **AC1: Given repo URL/GitHub auth When connected Then initial scan triggered automatically; progress bar updates**:
  - Implemented `RepoConnectModal` component (`apps/web/src/components/RepoConnectModal.tsx`) allowing GitHub OAuth integration & repository URL/branch connection.
  - Implemented `ScanProgressCard` component (`apps/web/src/components/ScanProgressCard.tsx`) displaying animated scan progress across scan phases (`cloning` -> `ast_parsing` -> `locator_extraction` -> `vector_indexing` -> `completed`).
  - Connecting a repository automatically initializes background scan execution and streams real-time percentage progress.

- **AC2: Given scan failure When error occurs Then human-readable message with retry button**:
  - `ScanProgressCard` detects scan failure state and displays clear human-readable error messages (e.g., *"Repository clone failed: Invalid credentials or branch main not found"*).
  - Renders a prominent **"Retry Scan"** button allowing workspace admins to instantly re-trigger the scan job.
