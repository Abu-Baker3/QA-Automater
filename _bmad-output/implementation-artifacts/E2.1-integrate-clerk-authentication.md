# E2.1 — Integrate Clerk Authentication

**Status:** done  
**Date:** 2026-08-10  
**Epic:** E2 — Authentication, Organizations & RBAC  

---

## User Story

As a **User**, I want to sign up and log in securely, so that I can access the platform.

---

## Acceptance Criteria

- **AC1:** Given an unauthenticated user, when accessing the dashboard, then redirect to Clerk login.
- **AC2:** Given a valid Clerk JWT, when calling the NestJS API, then the user_id is extracted and validated by auth guard.
- **AC3:** Given a Clerk webhook event (`user.created` / `user.updated`), when received at `/webhooks/clerk`, then sync the user record to PostgreSQL database `users` table.
