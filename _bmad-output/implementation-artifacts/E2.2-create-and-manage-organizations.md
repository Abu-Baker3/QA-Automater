# E2.2 — Create and Manage Organizations

**Status:** done  
**Date:** 2026-08-10  
**Epic:** E2 — Authentication, Organizations & RBAC  

---

## User Story

As a **User**, I want to create an Organization, so that my team has an isolated workspace.

---

## Acceptance Criteria

- **AC1:** Given an authenticated user, when creating an org with a name, then an org record is created in PostgreSQL and the user is assigned the `ADMIN` role.
- **AC2:** Given an org slug, when a duplicate slug creation is attempted, then return `409 Conflict`.
