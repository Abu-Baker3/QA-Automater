# E2.3 — Implement RBAC Middleware (Admin / Member)

**Status:** done  
**Date:** 2026-08-11  
**Epic:** E2 — Authentication, Organizations & RBAC  

---

## User Story

As a **Workspace Admin**, I want role-based permissions, so that only admins connect repos.

---

## Acceptance Criteria

- **AC1:** Given a user with `Member` role, when calling `POST /repositories`, then return `403 Forbidden`.
- **AC2:** Given a user with `Admin` role, when calling `POST /repositories`, then the request proceeds.

---

## Technical Tasks

- [x] **Task 1:** Create `@Roles(...)` decorator in `apps/api/src/auth/roles.decorator.ts`.
- [x] **Task 2:** Create `RolesGuard` in `apps/api/src/auth/roles.guard.ts` using NestJS `Reflector` to enforce role requirements.
- [x] **Task 3:** Create `RepositoriesController` in `apps/api/src/repositories/repositories.controller.ts` with `POST /repositories` protected by `@Roles('ADMIN')`.
- [x] **Task 4:** Register `RepositoriesModule` in `apps/api/src/app.module.ts`.
- [x] **Task 5:** Add unit tests for `RolesGuard` and `RepositoriesController` verifying AC1 & AC2.

## Dev Agent Record

### Implementation Plan
1. Define `@Roles('ADMIN', 'MEMBER')` metadata decorator.
2. Build `RolesGuard` checking `req.user.role` or `x-organization-role` header against required roles; throw `ForbiddenException` if insufficient role.
3. Build `RepositoriesController` with `POST /repositories` guarded by `ClerkAuthGuard` and `RolesGuard`.
4. Create unit tests covering `Member` role (403 Forbidden) and `Admin` role (201 Created).

### Completion Notes
- Implemented `@Roles('ADMIN', 'MEMBER')` decorator in `apps/api/src/auth/roles.decorator.ts`.
- Implemented `RolesGuard` in `apps/api/src/auth/roles.guard.ts` enforcing role requirements and throwing `ForbiddenException` (HTTP `403 Forbidden`) for unauthorized roles.
- Created `RepositoriesController` exposing `POST /repositories` guarded by `@Roles('ADMIN')`.
- Added unit tests for `RolesGuard` and `RepositoriesController`. All 18 tests in `@qa-automater/api` passed 100%.
