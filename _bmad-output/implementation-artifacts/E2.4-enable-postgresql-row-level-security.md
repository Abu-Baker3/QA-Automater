# E2.4 — Enable PostgreSQL Row-Level Security

**Status:** done  
**Date:** 2026-08-11  
**Epic:** E2 — Authentication, Organizations & RBAC  

---

## User Story

As a **Security Engineer**, I want RLS on tenant tables, so that defense-in-depth prevents data leakage.

---

## Acceptance Criteria

- **AC1:** Given RLS policy on repositories/tenant tables, when querying without `app.current_org_id()` context, then zero rows returned.
- **AC2:** Given valid `org_id` set via `SELECT app.set_org_context('...')::uuid`, when querying tenant tables, then only org rows are returned.
