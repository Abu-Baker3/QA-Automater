# E2.5 — Invite Team Members by Email

**Status:** done  
**Date:** 2026-08-12  
**Epic:** E2 — Authentication, Organizations & RBAC  

---

## User Story

As a **Workspace Admin**, I want to invite QA engineers, so that my team collaborates on test generation.

---

## Acceptance Criteria

- **AC1:** Given Admin sends invite (`POST /organizations/:orgId/invites`), when invitee accepts token (`POST /organizations/invites/accept`), then `MEMBER` role is assigned to the user for that organization.
- **AC2:** Given `MEMBER` role, when generating tests (`POST /tests/generate`), then allowed; when connecting repos (`POST /repositories`), then denied (`403 Forbidden`).
