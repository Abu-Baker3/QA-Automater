# E3.1 — Register GitHub App and OAuth Flow

**Status:** done  
**Date:** 2026-08-12  
**Epic:** E3 — GitHub Integration & Repository Management  

---

## User Story

As a **Workspace Admin**, I want to connect GitHub via OAuth, so that the platform can read my repositories.

---

## Acceptance Criteria

- **AC1:** Given Admin clicks Connect GitHub, when OAuth completes, then installation token stored in Secrets Manager (not DB plaintext).
- **AC2:** Given expired token, when scan attempted, then prompt re-auth with clear message.

---

## Technical Tasks

- [x] **Task 1:** Create `SecretsManagerService` (`apps/api/src/integrations/secrets-manager.service.ts`) for secure token storage and expiration checks (isolated from DB plaintext).
- [x] **Task 2:** Create `GitHubIntegrationService` (`apps/api/src/integrations/github-integration.service.ts`) to generate OAuth authorization URLs, handle installation callbacks, store tokens, and validate token freshness.
- [x] **Task 3:** Create `IntegrationsController` (`apps/api/src/integrations/integrations.controller.ts`) with `POST /integrations/github/connect` and `POST /integrations/github/callback` guarded by `ClerkAuthGuard` and `RolesGuard` (`@Roles('ADMIN')`).
- [x] **Task 4:** Register `IntegrationsModule` in `apps/api/src/app.module.ts`.
- [x] **Task 5:** Add comprehensive unit tests in `integrations.controller.test.ts`, `github-integration.service.test.ts`, and `secrets-manager.service.test.ts` verifying AC1 and AC2.
