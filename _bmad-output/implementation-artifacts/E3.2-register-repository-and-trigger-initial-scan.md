# E3.2 — Register Repository and Trigger Initial Scan

**Status:** done  
**Date:** 2026-08-12  
**Epic:** E3 — GitHub Integration & Repository Management  

---

## User Story

As a **Workspace Admin**, I want to select a repo and branch, so that analysis begins automatically.

---

## Acceptance Criteria

- **AC1:** Given connected GitHub, when `POST /repositories` with `full_name` and `branch`, then `202 Accepted` returned with `repository_id` and `scan_id` (and status `"queued"`).
- **AC2:** Given duplicate repo for organization, when registering, then return HTTP 409 Conflict.

- [x] **Task 1:** Create `RepositoriesService` (`apps/api/src/repositories/repositories.service.ts`) managing repository registration, duplicate detection per organization, and scan job queuing via `QueueService`.
- [x] **Task 2:** Update `RepositoriesController` (`apps/api/src/repositories/repositories.controller.ts`) with `RegisterRepositoryDto` validating `full_name`, `branch`, and optional `provider`, returning HTTP `202 Accepted` with `repository_id`, `scan_id`, and `status`.
- [x] **Task 3:** Ensure `RepositoriesModule` imports `QueueModule` and registers `RepositoriesService`.
