# E3.3 — List Accessible GitHub Repositories

**Status:** done  
**Date:** 2026-08-12  
**Epic:** E3 — GitHub Integration & Repository Management  

---

## User Story

As a **Workspace Admin**, I want to browse my GitHub repos in the UI, so that I can select one to connect.

---

## Acceptance Criteria

- **AC1:** Given valid GitHub token, when listing repos via `GET /integrations/github/repositories`, then return paginated list with `full_name`, `default_branch`, `name`, and `private` visibility status.
- **AC2:** Given token lacks repo scope (or token missing/invalid), when listing repos, then return HTTP 403 Forbidden with clear remediation steps.

---

- [x] **Task 2:** Add `GET /integrations/github/repositories` endpoint to `IntegrationsController` (`apps/api/src/integrations/integrations.controller.ts`) protected by `@Roles('ADMIN')`, `ClerkAuthGuard`, and `RolesGuard`.
