# E3.4 — Disconnect Repository and Purge Data

**Status:** done  
**Date:** 2026-08-12  
**Epic:** E3 — GitHub Integration & Repository Management  

---

## User Story

As a **Workspace Admin**, I want to disconnect a repo, so that my source code is removed from the platform.

---

## Acceptance Criteria

- **AC1:** Given Admin disconnects repository via `DELETE /repositories/:id`, when confirmed, then cascade delete repository, scans, elements, and jobs; schedule S3 purge job.
- **AC2:** Given disconnect completed, then revoke/clean up associated GitHub installation token from Secrets Manager.

---

## Technical Tasks

- [x] **Task 1:** Update `RepositoriesService` (`apps/api/src/repositories/repositories.service.ts`) with `disconnectRepository(orgId, repositoryId)` method handling cascade deletion, S3 purge job scheduling, and token revocation via `SecretsManagerService`.
- [x] **Task 2:** Add `DELETE /repositories/:id` endpoint to `RepositoriesController` (`apps/api/src/repositories/repositories.controller.ts`) protected by `@Roles('ADMIN')`, `ClerkAuthGuard`, and `RolesGuard`.
- [x] **Task 3:** Add unit tests in `repositories.service.test.ts` and `repositories.controller.test.ts` verifying AC1 & AC2.
