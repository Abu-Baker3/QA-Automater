# E4.3 — Track Scan Progress and Status API

**Status:** done  
**Date:** 2026-08-13  
**Epic:** E4 — Repository Scanner & Job Orchestration  

---

## User Story

As a **QA Engineer**, I want to poll scan status, so that I know when indexing completes.

---

## Acceptance Criteria

- **AC1:** Given running scan, when `GET /scans/{id}`, then return `phase`, `files_done`, `files_total`.
- **AC2:** Given completed scan, when `GET /scans/{id}`, then return `framework`, `element_count`, `completed_at`.

---

## Technical Tasks

- [x] **Task 1:** Create `ScansService` (`apps/api/src/scans/scans.service.ts`) managing scan state, progress updates (`phase`, `files_done`, `files_total`), and completion metadata (`framework`, `element_count`, `completed_at`).
- [x] **Task 2:** Create `ScansController` (`apps/api/src/scans/scans.controller.ts`) exposing `GET /scans/:id` protected by `ClerkAuthGuard` and `RolesGuard`.
- [x] **Task 3:** Create `ScansModule` (`apps/api/src/scans/scans.module.ts`) and register it in `AppModule` (`apps/api/src/app.module.ts`).
- [x] **Task 4:** Add unit tests in `scans.service.test.ts` and `scans.controller.test.ts` verifying AC1 & AC2.
