# E4.4 — Emit WebSocket Scan Progress Events

**Status:** done  
**Date:** 2026-08-14  
**Epic:** E4 — Repository Scanner & Job Orchestration  

---

## User Story

As a **QA Engineer**, I want real-time scan progress, so that I don't poll repeatedly.

---

## Acceptance Criteria

- **AC1:** Given subscribed client, when scan progresses, then receive `scan.progress` events with `percent`.
- **AC2:** Given scan completes, when event emitted, then `scan.complete` includes `element_count`.

---
