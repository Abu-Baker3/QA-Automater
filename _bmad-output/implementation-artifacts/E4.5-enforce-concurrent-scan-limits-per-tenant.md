# E4.5 — Enforce Concurrent Scan Limits per Tenant

**Status:** done  
**Date:** 2026-08-14  
**Epic:** E4 — Repository Scanner & Job Orchestration  

---

## User Story

As the **Platform**, I want to limit concurrent scans, so that fair usage across tenants is ensured.

---

## Acceptance Criteria

- **AC1:** Given org at 2 running scans, when 3rd scan requested, then queue job until slot becomes available. When a running scan completes, the 3rd scan auto-promotes to running.
- **AC2:** Given plan tier free, when exceeding daily scan quota (>= 10 daily scans per 24 hours), then return HTTP 429 (`Too Many Requests`) with upgrade message.
