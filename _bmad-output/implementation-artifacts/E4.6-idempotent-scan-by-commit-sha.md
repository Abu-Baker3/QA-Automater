# E4.6 — Idempotent Scan by Commit SHA

**Status:** done  
**Date:** 2026-08-15  
**Epic:** E4 — Repository Scanner & Job Orchestration  

---

## User Story

As the **Platform**, I want to skip re-parse for unchanged commits, so that resources are saved.

---

## Acceptance Criteria

- **AC1:** Given same `repository_id` (`repo_id`) + `commit_sha` already `completed` (`status === 'completed'`), when re-scan requested, then return existing `scan_id` (and scan record) without re-processing.
- **AC2:** Given new commit (or no existing completed scan for `repository_id` + `commit_sha`), when scan runs, then full pipeline executes.
