## User Story

As the **Scan Worker**, I want to detect React vs Next.js, so that the correct parser is used.

---

## Acceptance Criteria

- **AC1:** Given `package.json` with `"next"` dependency (in `dependencies` or `devDependencies`), when detect runs, then `framework = 'NEXTJS'`.
- **AC2:** Given `package.json` with `"react"` dependency only (and no `"next"`), when detect runs, then `framework = 'REACT'`.
- **AC3:** Given Vue, Angular, or unsupported `package.json` (or missing React/Next dependencies), when detect runs, then throws error listing supported frameworks (`"Unsupported framework: only React and Next.js repositories are supported."`).
