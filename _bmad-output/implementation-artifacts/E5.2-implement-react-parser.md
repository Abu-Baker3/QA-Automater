## User Story

As the **Platform**, I want to parse React component files, so that JSX elements are extracted.

## Acceptance Criteria

- **AC1:** Given `.tsx` or `.jsx` file with functional or class component, when parsed, then `components[]` (component names, file paths, export status) and `jsx_elements[]` (tag names, 1-indexed line numbers, props such as `data-testid`, `aria-label`, `role`, `id`, `name`, `type`) are populated.
- **AC2:** Given syntax error in one file, when parsing, then log error, continue scan across remaining files, and mark that file as `parse_failed: true`.
