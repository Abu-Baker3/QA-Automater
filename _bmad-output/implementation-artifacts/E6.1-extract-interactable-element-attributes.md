**Status:** done

## User Story

As the **Platform**, I want to extract testid, ARIA, roles, placeholders, links, so that locators are available for mapping.

---

## Acceptance Criteria

- **AC1:** Given input with `data-testid="email"`, when extracted, then locator candidate `strategy=testid`, `score >= 0.96` (`score = 0.98`).
- **AC2:** Given button with static text `"Sign In"`, when extracted, then `static_text` (`getByText('Sign In')`) and `role+name` (`getByRole('button', { name: 'Sign In' })`) candidates created.

2. Implemented `LocatorExtractor` (`workers/scan/src/locator-extractor.ts`):
