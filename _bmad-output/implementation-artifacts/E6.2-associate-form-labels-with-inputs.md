# E6.2 — Associate Form Labels with Inputs

**Status:** done  
**Date:** 2026-08-15  
**Epic:** E6 — Locator Extraction Engine  

---

## User Story

As the **Platform**, I want label↔input pairing, so that getByLabel locators are accurate.

---

## Acceptance Criteria

- **AC1:** Given `<label htmlFor="email">Email Address</label>` and `<input id="email" />`, when paired, then `label` locator candidate (`page.getByLabel('Email Address')`) rank $\le 2$ (`score = 0.92`).
- **AC2:** Given `aria-label="Search Query"` without a `<label>` element, when extracted, then `role+name` candidate (`page.getByRole('textbox', { name: 'Search Query' })`) is used.
