## User Story

As the **Platform**, I want ranked locators with stability tiers, so that users see high/medium/low quality.

## Acceptance Criteria

- **AC1:** Given `data-testid` present **When** scored **Then** `rank = 1`, `stability_tier = 'high'` (`score = 0.98 >= 0.90`).
