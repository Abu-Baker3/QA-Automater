# E6.4 — Persist UI Elements with Source Traceability

**Status:** done  
**Date:** 2026-08-15  
**Epic:** E6 — Locator Extraction Engine

## User Story

As a **QA Engineer**, I want `file:line` for every element, so that I can verify extraction in source.

---

## Acceptance Criteria

- **AC1:** Given extracted element **When** persisted **Then** `source_file` and `source_line` populated in database/scanned output.
- **AC2:** Given element detail API **When** queried **Then** `source_ref` returned as `{file}:{line}` (e.g. `app/login/page.tsx:42`).
