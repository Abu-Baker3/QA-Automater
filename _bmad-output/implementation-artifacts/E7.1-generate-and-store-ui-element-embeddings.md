**Status:** done  
**Date:** 2026-08-15  
**Epic:** E7 — UI Knowledge Base, Embeddings & Search

## User Story

As the **AI Pipeline**, I want vector embeddings per element, so that semantic retrieval works.

---

## Acceptance Criteria

- **AC1:** Given new `ui_element` **When** `content_hash` unchanged **Then** skip re-embed (idempotency optimization).
- **AC2:** Given 100 elements **When** embed batch runs **Then** upsert to `ui_element_embeddings` with `vector(1536)`.

## Dev Agent Record

### Implementation Plan
1. Exported vector embedding types in `packages/types/src/index.ts`.
2. Created `UiElementEmbeddingService` (`workers/ai/src/embedding-service.ts`):
   - Computes SHA-256 `content_hash` over tag name, text content, aria-label, testid, and source_ref.
   - Skips re-embedding when `content_hash` is unchanged (`skipped_count = 1`).
   - Generates 1536-dimensional vector embeddings (`vector(1536)`) and upserts into `ui_element_embeddings` store.
3. Created Unit Tests (`workers/ai/src/embedding-service.test.ts`):
   - AC1: Given unchanged `content_hash`, skips re-embed (`skipped_count = 1`, `embedded_count = 0`).
   - AC2: Given batch of 100 elements, upserts 100 embeddings each with `embedding.length === 1536`.
