## Acceptance Criteria Summary
- **AC1: OpenAI Structured JSON Output**:
  - Implemented `OpenAIProvider` class (`packages/shared/src/llm/openai.provider.ts`) executing completions with `response_format: { type: 'json_object' }`.
  - Parses JSON output and validates structure against provided schema (`schema.validator` or schema format).
- **AC2: Automatic Failover Retry to Anthropic**:
  - Implemented `FallbackLLMProvider` orchestrator (`packages/shared/src/llm/fallback.provider.ts`).
  - When calling completion, executes primary provider (`OpenAIProvider`). If primary fails (5xx, network error, or invalid JSON), logs warning, increments OTel metric counter `llm.completions.fallback`, and automatically retries with `AnthropicProvider` once.
