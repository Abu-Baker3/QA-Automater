## Acceptance Criteria Summary
- **AC1: Decompose Login User Story ($\ge 4$ steps, $\ge 1$ assert action)**:
  - Implemented `StoryAgent` (`packages/shared/src/llm/story-agent.ts`) and `TestPlanJsonSchema` with strict validator (`validateTestPlanIR`).
  - Ensures generated Test Plan IR contains at least 4 test steps and at least 1 `assert` action step.
- **AC2: LLM JSON Validation & Automated Retry Mechanism**:
  - If LLM response contains invalid JSON or fails step count/assertion criteria, `StoryAgent` automatically retries up to 2 additional times (3 total attempts).
  - Injects validation error message into retry prompt to guide LLM completion.
  - If validation fails on all 3 attempts, throws `StoryAgentException` and fails job with error.
