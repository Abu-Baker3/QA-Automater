## Acceptance Criteria Summary
- **AC1: `element_id` chosen ONLY from candidates list**:
  - Implemented `MappingAgent` (`packages/shared/src/llm/mapping-agent.ts`) and `validateStepLocatorMapping` validator function.
  - Enforces that `element_id` must match an ID in the provided candidate array (or be `null` if no element matches). Any off-list ID triggers validation failure & retry.
- **AC2: Step flagged for review when confidence < 0.85**:
  - `validateStepLocatorMapping` and rule engine post-enforcement require `needs_review: true` whenever `confidence < 0.85`.
- **AC3: Rationale cites `source_ref` when confidence ≥ 0.5**:
  - `validateStepLocatorMapping` and rule engine post-enforcement ensure `rationale` explicitly cites the mapped element's `source_ref` (e.g. `app/login/page.tsx:24`).
