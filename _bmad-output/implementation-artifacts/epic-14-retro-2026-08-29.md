## Epic-by-Epic Retrospective Highlights

### 1. Foundation & Infrastructure (Epics E1 – E3)
- **What Went Well**:
  - Pnpm workspace monorepo with Turborepo enabled rapid, parallel builds across `@qa-automater/types`, `@qa-automater/shared`, `@qa-automater/database`, `@qa-automater/ui`, `apps/api`, `apps/web`, and workers (`scan`, `ai`, `export`).
  - Integrated Clerk authentication with custom NestJS RBAC guards and PostgreSQL Row-Level Security (RLS) policies for multi-tenant isolation.
  - Built GitHub App OAuth authentication flow with webhook event dispatch and installation token management.
- **Challenges & Learnings**:
  - Setting up pgvector extensions and connection pooling required tuning PgBouncer parameters for RLS session variable propagation (`app.current_org_id`).

### 2. Scanning Engine, Framework Parser & Locators (Epics E4 – E6)
- **What Went Well**:
  - Implemented BullMQ scan job queue backed by Redis with concurrent per-tenant job limits, commit-SHA idempotency, and real-time WebSocket progress reporting.
  - Implemented framework detection for React & Next.js App Router with AST parsing, JSX element extraction, form-label association, and stability score computation (`testid` > `role` > `label` > `placeholder` > `text` > `css`).
- **Challenges & Learnings**:
  - Complex AST parsing across different JSX/TSX patterns required fallbacks for dynamic components and custom hooks.

### 3. UI Knowledge Base, AI Pipeline & Review Queue (Epics E7 – E10)
- **What Went Well**:
  - Built pgvector embeddings pipeline (`@qa-automater/ai-worker`) with OpenAI text-embedding-3-small and hybrid RAG retrieval combining vector similarity, BM25 keyword match, and component graph traversal.
  - Implemented Story Agent (decomposition to Test Plan IR) and Mapping Agent (candidate locator mapping with confidence scores and source citations).
  - Built Human-in-the-Loop review queue API & dashboard UI with confidence-based gating (`<0.85 confidence` triggers manual review).

### 4. Codegen, Multi-Channel Export & UI Wizard (Epics E11 – E13)
- **What Went Well**:
  - Implemented Playwright Code Mapper, Page Object generator, and Spec Generator producing type-safe TypeScript Playwright test suites.
  - Built presigned S3 ZIP exporter and automated GitHub Pull Request exporter creating branches and PRs directly on user repositories.
  - Built Next.js web application with modern UI components (`TestGenerationWizard`, `RepoConnectModal`, `ScanProgressCard`, `ExportActionsCard`).

### 5. Security, Observability & Operations (Epic E14)
- **What Went Well**:
  - Implemented Redis token-bucket API rate limiting per organization (`E14.1`).
  - Implemented AWS KMS AES-256 envelope encryption for repository tarball snapshots and Secrets Manager token storage (`E14.2`).
  - Implemented OpenTelemetry structured JSON logger and sliding-window PagerDuty alert manager (`E14.3`).
  - Implemented AI Evaluation Harness (`E14.4`) with a 20 golden story / 5 repo regression benchmark enforcing an 80% locator precision gate in CI/CD pipelines.
